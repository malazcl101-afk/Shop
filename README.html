Welcome to Shop Ledger

HarborNestDigital · Small-business sales, stock and profit organizer

Start in a few minutes

  1. Unzip the folder, keep all files together and open index.html in your browser.
  2. Add each inventory item with opening quantity, unit cost, ask price and a reorder level. Add suppliers if you want to link them to purchases.
  3. Log purchases to add units, sales to subtract units, and operating expenses separately. Dashboard and profit reports update automatically.

Understand the numbers

Revenue is the quantity sold times sale price. Cost of goods sold (COGS) is saved from an item’s unit cost at the time of sale. Gross profit is revenue minus COGS; net profit also subtracts operating expenses. Purchase spend is displayed separately and is not deducted again from profit. Break-even units are an estimate based on average listed unit margin, not a guaranteed forecast.

Personalize your workspace

Customize & backup offers 11 color themes, modern/classic/large fonts, three spacing choices, card style and high contrast. Change your business name and currency display. Your selections save immediately. Restore appearance defaults changes only the look. Currency display does not convert values.

Backup, transfer and privacy

Records live only in this browser profile on this device. They do not automatically sync. Download a JSON backup frequently and store it outside the browser. To move devices, export on the old one and import on the new one. Import replaces existing records there, so back those up first. Clearing browser data, private mode or changing browser profiles can remove entries.

Phones and offline access

The downloaded files open directly on computers without internet. For mobile installation, host the files on HTTPS, open the link once online, then use Safari Share → Add to Home Screen or Chrome menu → Install/Add to Home Screen. The hosted app can cache its files for offline use after that first visit. The seller may provide an HTTPS link; this download itself does not include hosting.

Troubleshooting

  • Nothing showing? Confirm you opened the same browser profile, or import your JSON backup.
  • Cannot record a sale? Add the inventory item first and check available quantity.
  • Restore fails? Choose a JSON file exported by Shop Ledger.
  • Install missing? Use a current browser and HTTPS address; direct local files may not offer installation.
