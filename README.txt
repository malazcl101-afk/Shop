HarborNestDigital

1. Unzip the folder; keep its files together. Open index.html in a current Chrome, Edge, Safari or Firefox browser.
2. Add inventory items with opening quantity, unit cost, sale price and reorder level. Then record purchases, sales and operating expenses.
3. Open Overview, Profit calculator and Monthly report for live figures. Sale COGS is saved when each sale is recorded; later item cost changes do not rewrite previous profit.
4. Customize & backup has 11 themes, fonts, spacing, card styles, high contrast, currency display and JSON export/import.
5. Records are saved only in this browser profile and device. They do not sync automatically. Clearing browser/site data can remove them; export backups regularly.
6. To transfer records, export JSON on one device and import it on the other. Import replaces current records in that browser.
7. On phones, an HTTPS host is needed for Add to Home Screen; the seller may provide a link. The downloaded files open directly on a computer, without internet.

Currency selection changes symbols, not saved amounts. This is an organization tool, not tax or accounting advice. No bank connection, online orders, shared accounts or automatic reminders. Contact HarborNestDigital via your Etsy order for help.
